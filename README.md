# HireBot (demo)

An AI assistant to screen job applicants' CVs. Applicants chat with the bot about open roles
and upload their CV. The bot summarises each CV for recruiters and ranks candidates to
produce a shortlist.

It uses OpenAI for the chat and Anthropic for CV summaries.

> This repository is a deliberately non-compliant demo target for EU-Bridge. Do not deploy it.
> It also contains harmless code on purpose (startup and error logging, page-view analytics),
> so you can check that EU-Bridge does not flag everything.
